# Mapping viromes to microbiomes across a permafrost chronosequence (demo pipeline)

**Motivating question (from project brief):** How do microbial and viral community
composition change across an ancient-permafrost age chronosequence (Pleistocene →
Holocene / thaw front), and can we link phages to their bacterial hosts to understand
host-virus interactions relevant to carbon cycling on thaw?

## What this demo does

No real permafrost metagenomic/metaviromic sequencing data was available at prototyping
time, so this project simulates paired microbiome and virome relative-abundance tables
across a 24-sample age chronosequence, with three deliberately-built ecological signals,
then runs an analysis pipeline to recover them:

1. **Directional community turnover with age** — a "dormant/cryophile" bacterial guild
   dominates older (deep Pleistocene) samples, a "fast-responder" guild dominates
   younger/thaw-front samples, consistent with reactivation of dormant cells on thaw.
2. **Kill-the-winner phage-host coupling** — each simulated phage is assigned a specific
   bacterial host and its abundance tracks that host's abundance (with noise) across
   samples — the co-abundance signal that host-prediction pipelines exploit in real
   viral metagenomics.
3. Diversity/activity differences across the chronosequence.

## Files

| File | Purpose |
|---|---|
| `simulate_metagenome.py` | Simulates microbiome + virome relative-abundance tables, sample metadata, and ground-truth phage→host links across the chronosequence |
| `analyze_virome_microbiome.py` | Full analysis: alpha diversity trend, Bray-Curtis PCoA ordination (both communities), and co-abundance-based virus-host linkage prediction, validated against ground truth |
| `results/` | Abundance tables, metadata, figures, and prediction outputs (generated by running the scripts) |

## How to run

```bash
python3 simulate_metagenome.py            # writes results/*_abundance.csv, sample_metadata.csv
python3 analyze_virome_microbiome.py       # writes diversity/ordination/linkage results + figures
```

## Key results (from the included run)

- **Ordination** (`beta_diversity_ordination.png`) cleanly separates samples along the
  chronosequence in both the microbiome and virome, confirming that community turnover
  with permafrost age is detectable from Bray-Curtis dissimilarity alone — exactly the
  kind of exploratory figure a real chronosequence study would lead with.
- **Virus-host linkage** via Spearman co-abundance correlation (`predicted_host_links.csv`)
  recovered the correct simulated host for a large majority of phages (precision ≈0.96,
  recall ≈0.88 against ground truth at a ρ ≥ 0.5 threshold in the included run) —
  demonstrating that co-abundance is a viable line of evidence for host prediction in this
  kind of chronosequence design, to be combined with sequence-based methods on real data.

## Honest limitations / what the real project would add

- Real virome/microbiome relative-abundance tables come from metagenomic assembly, binning,
  and taxonomic/functional annotation of raw shotgun reads (or single-cell genomics, per the
  brief) — this simulation starts from abundance tables directly and does not model reads,
  assembly, or annotation error.
- Real host prediction pipelines (e.g. iPHoP, vConTACT2, CRISPR spacer matching,
  k-mer/oligonucleotide frequency similarity) combine several independent signals; this demo
  implements only the co-abundance signal, chosen because it's the one most directly testable
  against a chronosequence's cross-sample structure.
- The "dormant vs fast-responder" guild split and kill-the-winner coupling are simplified
  caricatures of real microbial ecology; a real analysis would derive guild structure from
  actual taxonomy/function rather than assuming it.
- Sample ages here are a synthetic linear gradient; real chronosequence samples would carry
  actual radiocarbon or stratigraphic age estimates with associated uncertainty.
